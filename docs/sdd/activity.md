# Уведомления и проверка работы

Колокольчик показывает число непрочитанных уведомлений. Нажатие на запись отмечает её прочитанной и ведёт к выпуску Git, подключению, поручению или форме публикации. Доступна общая отметка «прочитано». Лента ограничена 80 записями, хранится в браузере на адресе локального приложения и восстанавливается после перезагрузки. Свежие события формируются из последних выпусков Git, результатов синхронизации, завершённых операций подключения и сроков открытых поручений. Повторное чтение одного состояния не создаёт уведомление заново. Поручение считается просроченным со дня, следующего за сроком, по московскому времени.

Кнопка «Проверить работу» вызывает локальный `POST /api/workspace-health`. Ответ содержит отдельные проверки приложения и ревизии из Git при её наличии, карты, реестра Excel, запуска Git, последней синхронизации и операций браузера. Для чтения отчётов и получения выгрузок указывается последнее успешное время, если оно сохранено. Локальная проверка читает метаданные подключений и запускает `git --version`. Проверка общей версии по сети доступна отдельно и использует настроенный способ входа. В старых записях время действий браузера может отсутствовать.

Модель ленты находится в `public/activity-feed.js`, представление в `public/activity-view.js`, диагностика в `src/workspace-health.mjs`. Тесты ленты проверяют повторное чтение, переходы по типу события и сохранение прочитанности. Тесты представления проверяют состояние кнопок и подсказки проверки.
