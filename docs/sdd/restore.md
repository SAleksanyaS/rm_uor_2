# Резервная копия и восстановление

Откройте «Настройка → Профиль и Git» и скачайте текущую резервную копию, если нужно сохранить состояние перед переносом. Выберите JSON-копию РМ УОР и проверьте дату и объём данных в предпросмотре. Нажмите «Заменить данные копией». Карта, исходники, правки карточек, справочник, черновики, настройки расчёта и сохранённая общая версия будут восстановлены из выбранного файла.

Браузерный архив, записи шагов и сессии хранятся в отдельном рабочем пространстве. Восстановление работает только с бизнес-данными. Параметры нового репозитория из копии вступают в силу после явной проверки и сохранения профиля. Отличающийся путь к исполняемому файлу Git очищается.

| Метод и маршрут | Результат |
| --- | --- |
| `GET /api/backup` | `rm-uor-backup.json` с форматом `rm-uor-workspace-v1`. Содержит `exportedAt`, `workspace` и исходники `originals: [{id, base64}]` |
| `POST /api/restorepreview` | Проверяет загруженную копию и возвращает сводку и токен `token` |
| `POST /api/restore` | Проверяет тот же файл и токен `x-rmuor-restore-token`, сохраняет исходники и заменяет состояние в очереди рабочих записей |

Оба POST принимают сырые UTF-8 байты JSON размером до 128 МиБ и требуют `x-rmuor: 1`. Исходник ограничен 20 МиБ. Проверка сверяет состав, размер, SHA-256 и возможности чтения каждого исходника. В копиях прежних версий поддерживаются отсутствующий указатель активной карты и старый массив статусов ДИТ.

Токен связан с содержимым файла и текущим рабочим состоянием. Если данные изменились или сервер перезапустился, откройте предпросмотр заново. При отказе текущее рабочее состояние остаётся доступным. Из прежних исходников могут сохраниться файлы, на которые восстановленная копия уже не ссылается.
