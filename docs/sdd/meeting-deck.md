# Презентация «К встрече»

Режим находится в «Итоги → Еженедельный отчёт». Оперативный отчёт сохраняет календарь, карточки кураторов, сравнение и поручения. На карте новых панелей нет.

## Конструктор

Выбираются период, весь ДИТ со всеми ИТ-лидерами или один лидер, название и заметка к сводке. Разделы включаются и переставляются. По умолчанию доступны сводка, график по лидерам, риски, карточки лидеров, сравнение срезов, открытые поручения и полный перечень целей. Сводку кураторов можно включить для общего отчёта. Не применимые к охвату или пустые дополнительные разделы пропускаются. Сравнение появляется при наличии двух датированных Excel-срезов за один период. Даты и неделя берутся из оперативного режима.

Кнопка «Сохранить настройки» сохраняет один локальный шаблон. В него попадают охват, название и разделы в их порядке. Дата и период выпуска, данные и заметка задаются заново при открытии. Шаблон входит в резервную копию.

## Данные слайда

- Руководительская сводка ДИТ считает уникальные применимые цели. Диаграмма лидеров использует отдельно назначения каждого лидера.
- Полный перечень ДИТ сохраняет все цели из активной карты. Неприменимые отмечаются явно и остаются за пределами сводных чисел. Перечень лидера содержит его активные назначения.
- У каждого факта видны применимые единицы и источник. Ноль сохраняется. Если у назначения несколько КР, отчёт указывает количество и строки Excel. Для итогового показателя ДИТ используются отдельное измерение или итоговая строка по действующим правилам.
- Совпадают данные в браузере и на выгруженных слайдах. Сервер сериализует модель, считает SHA-256 и проверяет его перед экспортом. Если состояние или параметры изменились, требуется новый предпросмотр.
- Карточки, риски и подробные списки разбиты на страницы. Каждый раздел сохраняет заданный порядок. PPTX включает нативные редактируемые формы и текст в пропорциях 16:9. Экспорт работает локально, без установки пакетов и без открытия офиса на сервере.

Дополнительный XLSX модели зрелости содержит данные блока, трайба, кластера, команды, этапа, группы и метрики. Его итоговые строки и детализация показывают 56 из 58 команд. Для использования в датированных слайдах и разрезах лидеров потребуются дата и подтверждённые соответствия кластеров. Для общего отчёта используется действующая карта и реестр статусов.

## Точки входа

| Метод | Запрос и ответ |
| --- | --- |
| `POST /api/meeting-preview` | `{config, sourceId?, previousId?, week?}`. Возвращает `{report, reportId}` с упорядоченными слайдами |
| `POST /api/meeting-pptx` | Те же данные и `reportId`. Возвращает вложение PowerPoint. Несовпадение модели даёт `409 STALE_VIEW` |
| `POST /api/meeting-template` | `{config, expectedRevision}`. Возвращает обновлённое состояние. Конкурентная правка требует повторного чтения |

`public/meeting-config.js` нормализует конфигурацию. `src/meeting-report.mjs` использует проекции цели и лидера и собирает содержание слайдов. `public/meeting-view.js` показывает модель и форму. `src/meeting-pptx.mjs` формирует архив PresentationML из модели.
