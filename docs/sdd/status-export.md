# Сводная по статусам

В «Итоги → Сводная по статусам» показываются имя шаблона, его периоды и предпросмотр переноса. В обычной установке шаблон задаёт `seed/status-register.json`. При запуске с отдельным рабочим пространством используется его текущий реестр. По умолчанию берутся опубликованные данные. Флажок «Включить локальные черновики» позволяет использовать актуальные локальные правки. Учитываются действующие цели, строки ДИТ и назначения ИТ-лидерам.

Перенос использует тройку «цель, участник, период». Если есть подтверждённая связь в «Сверке КР», записи с предварительными связями исключаются из выбора. В столбец T для квартала или V для года записывается статус из легенды Excel при наличии ровно одной подходящей строки. При нескольких строках, отсутствии связи или неизвестном статусе причина показывается в предпросмотре.

Лист «Статусы РМ УОР» содержит каждую включённую запись, статус, факт, план, единицу, дату, комментарий и результат переноса. В действующем шаблоне нет сопоставленных итоговых строк ДИТ, поэтому записи ДИТ видны на этом листе. Прогнозы, факты, планы и формулы существующего реестра остаются данными исходной книги. Сводные таблицы получают настройку обновления при открытии в Excel. Исходная книга хранится по контрольной сумме и скачивание создаёт её отдельную копию.
