# Презентация к еженедельной встрече

Режим «К встрече» в недельном отчёте использует ту же карту, Excel и статусы. Карта целей сохраняет текущий интерфейс. Один шаблон сохраняет название, охват и порядок разделов. Для каждого выпуска пользователь выбирает период и добавляет комментарий.

| Задача | Приёмка |
| --- | --- |
| Модель отчёта | Вся карта и все лидеры или один лидер. Ноль, отсутствие статуса и неприменимость различаются. Риск ДИТ и риск кластера остаются разными строками. Список целей разбивается на читаемые страницы |
| Конструктор | Выбор периода и лидера, включение и порядок разделов, заметка и сохранение локального шаблона. Предпросмотр с переключением слайдов |
| PowerPoint | Нативный редактируемый PPTX по той же модели. Изменение данных после предпросмотра требует повторного просмотра |
| Проверка | Покрытие сводки, одного лидера, пограничных пустых данных и выгрузки. Проверка в браузере и на готовом PPTX. Запуск обычной командой без установки пакетов |

Дополнительная книга модели зрелости рассматривается как будущая детализация отдельной цели. Она не заменяет реестр достижения целей и не загружается автоматически.
