# Карта, срезы и решения по рискам

Этот план продолжает [работы по встрече](2026-11-16-dit-overview-and-reports.md). Карта сохраняет короткую сводку, операции подготовки и восстановления остаются в настройках.

| Работа | Изменение | Приёмка |
| --- | --- | --- |
| Карта | Дата подтверждённого Excel, даты фактов ДИТ, счётчики заполненности. Явное исключение цели для периода в настройке | Пустое значение отлично от нуля, отсутствие записи отлично от неприменимости. Счётчики и переход по риску используют один набор целей |
| «Срезы ДИТ» | Журнал наблюдений по датам, сравнение точных дат, отметки локального и опубликованного результата. Git хранит отдельный файл истории | Равные периоды, разные даты, понятны отсутствующие записи и разные единицы. История сохраняется при обновлении старым клиентом |
| «Год качества» | Пилот SW26.3 по явно сопоставленным колонкам команды, порога и факта, разбор отклонений и экспорт | Два разных тестовых файла, повторяемый ID, неполный срез, дубли, неверный диапазон. Бизнес-приёмка проводится на двух утверждённых выгрузках |
| Поручения | Создание из риска, исполнитель, срок, следующий шаг и статусы. Пока используется локальный трекер | Поручение открывается на следующей неделе, просрочка выделяется, повторный запрос не теряет данные. [Спецификация адаптера СберТрека](../sdd/sbertrack-tasks.md) |
| Сохранность и выпуск | Предпросмотр и безопасное восстановление, две независимые установки, обновление без потери .local, запуск и проверка архива | Подмена оригинала или устаревший предпросмотр блокируют восстановление. Результат Git читается второй установкой. Целевые ОС проверяются по доступной среде |

Даты в сравнении обозначают даты наблюдений. Пустые строки на выбранную дату не переносятся из соседнего среза. Согласование корпоративных данных, прав записи в СберТреке и приёмка на физических ноутбуках проводятся в рабочей среде.
